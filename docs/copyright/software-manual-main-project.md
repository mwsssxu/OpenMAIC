# 侧伴 Web 端商业策略研究平台 V1.0.0 软件说明书

## 一、概述

### 1.1 软件名称

侧伴 Web 端商业策略研究平台

### 1.2 版本号

V1.0.0

### 1.3 软件简介

侧伴 Web 端商业策略研究平台是一款基于多智能体协同教学的 AI 交互式学习系统。软件采用 Next.js + React 技术架构，面向浏览器用户提供课程生成、课程播放、多人课堂协作、白板互动、问答悬赏、Token 充值和企业学习管理等功能。

用户可通过邮箱账号登录系统，输入学习主题或业务问题，由 AI 自动生成课程大纲、课堂场景和智能体角色，并在 Web 课堂中完成幻灯片学习、测验互动、语音播放、白板协作和实时聊天。系统同时提供积分与 Token 体系，支持问答悬赏、学习激励和 AI 内容生成资源管理，适用于个人学习、商业策略研究、团队培训和企业知识沉淀等场景。

## 三、软件功能说明

### 3.1 用户认证模块

**功能概述**：提供账号注册、登录、身份保持和接口鉴权能力。

**详细功能**：

1. **邮箱密码登录**：用户输入邮箱和密码提交认证请求，认证成功后进入系统首页。
2. **新用户注册**：支持邮箱、密码和可选昵称注册，密码长度需不少于 6 位。
3. **错误提示**：登录失败、注册失败、密码不符合要求等情况均在页面展示错误信息。
4. **登录态保护**：课程、企业、支付等业务页面在未登录时自动跳转至登录页。
5. **Token 管理**：前端通过认证上下文维护访问令牌，并在调用后端接口时携带鉴权信息。

### 3.2 首页仪表盘模块

**功能概述**：为用户提供学习入口、资源余额和核心业务快捷入口。

**详细功能**：

1. **用户信息展示**：页面头部显示当前用户昵称或邮箱。
2. **快速操作入口**：提供创建课程、我的课程、AI 讨论等常用入口。
3. **学习统计**：展示课程数量、学习时长、积分余额和 Token 余额。
4. **使用提示**：提供课程主题输入、积分兑换、多人课堂、智能体讨论等使用提示。
5. **业务跳转**：支持跳转至课程创建、课程列表和课堂播放等核心页面。

### 3.3 课程管理模块

**功能概述**：集中展示和管理用户已创建的课程。

**详细功能**：

1. **课程列表**：以卡片形式展示课程名称、描述和创建日期。
2. **课程播放入口**：用户可点击课程卡片进入对应课堂播放页面。
3. **课程删除**：支持删除已创建课程，删除前进行确认提示。
4. **空状态引导**：用户未创建课程时，引导创建第一个 AI 课程。
5. **课程统计**：展示课程总数、学习时长和互动次数等概览信息。

### 3.4 课程创建模块

**功能概述**：根据用户输入的课程主题自动生成课程大纲和智能体角色，并创建完整课堂。

**详细功能**：

1. **主题输入**：用户输入课程主题，可补充课程描述。
2. **AI 大纲生成**：系统调用后端生成课程大纲，展示场景标题、场景类型和顺序。
3. **智能体生成**：系统根据课程主题和大纲自动生成教师、助教、学生等智能体配置。
4. **默认智能体降级**：智能体生成失败时，自动尝试使用系统默认智能体配置。
5. **课程确认创建**：用户确认后创建课程记录，并按大纲逐个生成课程场景。
6. **重新生成**：支持清空当前大纲与智能体配置，重新发起生成流程。

### 3.5 课程播放模块

**功能概述**：提供 Web 端交互式课堂播放体验，支持场景切换、课件渲染、语音播放、白板和协作聊天。

**详细功能**：

1. **课程加载**：根据课程 ID 获取课程信息、场景内容和智能体配置。
2. **场景导航**：支持上一页、下一页切换，并展示当前场景序号和课程进度条。
3. **场景类型渲染**：支持幻灯片、测验、互动和项目式学习等场景类型。
4. **幻灯片画布渲染**：根据元素坐标渲染文本、形状、线条和图表等内容。
5. **测验展示**：展示题目和选项，供用户进行课堂互动。
6. **播放控制**：提供播放、暂停、继续和停止等语音播放控制。
7. **聚光灯与激光笔效果**：播放引擎可触发聚光灯和激光笔视觉效果，突出讲解元素。
8. **智能体选择**：展示课程智能体角色，支持切换当前对话角色。
9. **白板覆盖层**：用户可打开课堂白板进行绘制和协作。
10. **协作侧栏**：支持显示在线参与者、课程智能体和聊天面板。
11. **错误与重试**：课程加载失败时显示错误提示并提供重试按钮。

### 3.6 实时协作模块

**功能概述**：通过 WebSocket 和 CRDT 技术支持多人课堂同步。

**详细功能**：

1. **协作连接状态**：课堂页面展示 WebSocket 或 CRDT 连接状态。
2. **参与者列表**：协作侧栏展示当前课堂参与者。
3. **白板同步**：通过 Yjs 数据结构和 WebSocket 服务同步白板元素。
4. **课堂聊天**：支持课堂内消息交流，并可结合选中的智能体进行对话。
5. **场景内协作**：在课程播放过程中同时进行讲解、白板和聊天互动。

### 3.7 问答悬赏模块

**功能概述**：提供知识问答社区，用户可发布问题、回答问题并通过积分悬赏激励优质解答。

**详细功能**：

1. **问题列表**：展示问题标题、发布者、创建时间、浏览量、回答数和悬赏积分。
2. **排序筛选**：支持按最新、最高悬赏和最热门排序。
3. **发布问题**：用户可填写标题、问题内容、悬赏积分和标签。
4. **积分余额提示**：发布问题时显示当前积分余额，并限制悬赏上限。
5. **问题详情**：展示问题正文、浏览量、悬赏信息和回答列表。
6. **提交回答**：用户可在问题详情页提交回答内容。
7. **投票评价**：支持对回答进行赞成或反对投票。
8. **采纳答案**：支持采纳回答并标记已解决状态。

### 3.8 Token 支付模块

**功能概述**：提供 Token 套餐购买、支付方式选择和订单创建能力。

**详细功能**：

1. **余额展示**：显示当前用户 Token 余额。
2. **套餐选择**：展示可购买套餐、价格、Token 数量和赠送额度。
3. **支付方式选择**：支持微信支付和支付宝支付入口。
4. **订单详情**：根据所选套餐展示价格、获得 Token 数和赠送数量。
5. **订单创建**：调用后端创建支付订单。
6. **开发环境模拟支付**：开发环境下可模拟支付成功并刷新余额。
7. **生产支付预留**：生产环境预留微信支付参数和支付宝跳转逻辑。

### 3.9 企业学习管理模块

**功能概述**：面向企业用户提供团队学习、成员邀请、课程管理和学习数据统计。

**详细功能**：

1. **企业账户创建**：填写企业名称、行业、规模和套餐类型创建企业账户。
2. **企业信息展示**：展示企业名称、所属行业、套餐类型和当前用户角色。
3. **成员邀请**：管理员可批量输入邮箱邀请成员，并指定成员角色。
4. **成员管理**：展示成员昵称、邮箱、角色和加入日期。
5. **企业课程**：展示企业已分配课程、必修标记和截止日期。
6. **统计概览**：展示团队成员、活跃成员、课程完成数和学习小时数。
7. **报表入口**：提供学习报表标签页，为后续详细报表扩展预留入口。

### 3.10 API 通信模块

**功能概述**：封装前端与后端服务之间的数据通信。

**详细功能**：

1. **认证接口**：支持登录、注册、当前用户信息获取等接口调用。
2. **课程接口**：支持课程列表、课程详情、课程创建、场景创建和课程删除。
3. **生成接口**：支持课程大纲生成、智能体生成和默认智能体获取。
4. **问答接口**：支持问题、回答、投票和采纳相关接口调用。
5. **支付接口**：支持套餐查询、余额查询、订单创建和模拟支付。
6. **企业接口**：支持企业信息、成员、课程和统计数据读取与维护。

## 四、系统结构说明

### 4.1 总体架构

系统采用前后端分离架构。Web 前端负责页面展示、交互状态、路由跳转和实时协作界面；Python 后端负责用户认证、课程数据、AI 生成、问答、支付、企业管理和数据库持久化；WebSocket 服务负责课堂实时协作和白板同步。

### 4.2 前端目录结构

| 目录 | 说明 |
|------|------|
| `src/app` | Next.js App Router 页面与路由 |
| `src/app/(auth)` | 登录、注册等认证页面 |
| `src/app/(main)` | 首页、课程、问答、支付、企业等业务页面 |
| `src/components` | 通用组件、协作组件和 UI 基础组件 |
| `src/lib` | API 客户端、认证上下文、状态管理、播放引擎和 WebSocket 客户端 |
| `src/lib/stores` | Zustand 状态存储 |
| `src/lib/websocket` | 协作客户端与白板同步逻辑 |
| `src/components/collaboration` | 白板、聊天、参与者列表等协作组件 |

### 4.3 核心数据流程

1. 用户通过登录页提交账号密码，后端返回访问令牌。
2. 前端保存登录态并进入首页，加载 Token、积分和课程统计。
3. 用户输入课程主题，前端调用 AI 生成接口获取课程大纲和智能体配置。
4. 用户确认创建后，系统创建课程记录并逐个生成课堂场景。
5. 用户进入课堂播放页，前端加载课程场景并初始化播放引擎。
6. 多人协作时，前端建立 WebSocket 连接并同步白板、聊天和参与者状态。
7. 用户在问答、支付、企业模块中的操作通过 API 客户端提交至后端服务。

## 五、技术特点

### 5.1 多智能体协同教学

软件通过教师、助教、学生等智能体角色模拟真实课堂中的多方互动。课程创建时，系统根据课程主题、大纲和描述自动生成智能体名称、角色、人设、头像颜色和优先级。课堂播放时，用户可选择不同智能体作为当前对话对象，实现差异化的教学讲解、答疑和讨论体验。

### 5.2 AI 课程生成流程

软件将课程创建流程拆分为主题输入、大纲生成、智能体生成、课程创建和场景生成等步骤。前端负责采集用户需求和展示生成结果，后端负责调用大模型生成结构化课程内容。大纲数据包含场景标题、类型、描述和顺序，便于后续渲染为幻灯片、测验、互动或项目式学习场景。

### 5.3 Web 课堂播放引擎

软件内置 WebPlaybackEngine 课堂播放引擎，统一管理当前场景、播放状态、场景切换、语音播放、聚光灯和激光笔效果。播放引擎通过回调机制驱动页面状态更新，使课堂内容渲染、教学节奏控制和视觉强调效果保持一致。

### 5.4 响应式画布渲染

课程播放页采用固定设计视口和响应式缩放结合的方式渲染课件元素。文本、形状、线条、图表等元素根据原始坐标和当前容器尺寸计算缩放比例，保证不同屏幕宽度下课件布局尽量保持一致。

### 5.5 实时协作与白板同步

软件采用 WebSocket 和 Yjs CRDT 技术实现多人课堂协作。白板数据通过 CRDT 结构同步，降低多人同时编辑时的冲突风险；课堂连接状态、参与者列表和聊天面板为协作学习提供实时反馈。

### 5.6 前后端分离与模块化设计

软件采用 Next.js 前端和 Python API 后端的分离架构。前端按页面、组件、状态、API 客户端、播放引擎和协作客户端进行模块化组织，便于独立维护和扩展；后端负责认证、课程、问答、支付和企业管理等业务能力。

### 5.7 账户资源与激励体系

软件同时维护 Token 和积分两类账户资源。Token 主要用于 AI 生成和增值服务消耗，积分主要用于问答悬赏和学习激励。首页、问答发布页和支付页均提供资源余额展示，帮助用户了解资源使用情况。

### 5.8 安全机制

1. **登录鉴权**：业务页面通过登录态进行访问保护，未登录用户自动跳转至登录页。
2. **令牌传输**：前端调用后端接口时通过 Authorization 请求头携带访问令牌。
3. **输入校验**：注册密码长度、课程主题、问题标题和回答内容等关键输入均进行基础校验。
4. **删除确认**：课程删除操作前弹出确认提示，降低误操作风险。
5. **支付隔离**：开发环境使用模拟支付流程，生产环境保留真实支付对接逻辑。
6. **权限区分**：企业模块根据用户角色展示管理员操作，如成员邀请和企业管理。

## 七、主要操作流程

### 7.1 用户登录流程

1. 用户访问系统地址 `http://localhost:8081/`。
2. 系统检测登录状态，未登录时跳转至 `/login`。
3. 用户输入邮箱和密码并提交登录。
4. 登录成功后进入首页，系统加载课程数、Token 余额和积分余额。

### 7.2 创建课程流程

1. 用户从首页或课程列表进入 `/classrooms/create`。
2. 输入课程主题和可选课程描述。
3. 点击“生成大纲和智能体”，系统生成课程大纲和智能体配置。
4. 用户查看大纲预览和智能体配置。
5. 点击“确认创建”，系统创建课程并生成场景。
6. 创建完成后自动进入课程播放页。

### 7.3 课堂学习流程

1. 用户从课程列表点击“播放”进入课堂。
2. 系统加载课程场景、进度和智能体配置。
3. 用户通过上一页、下一页浏览课堂场景。
4. 用户可点击播放、暂停、继续或停止控制语音讲解。
5. 用户可打开白板或协作侧栏，与其他参与者和智能体互动。

### 7.4 问答悬赏流程

1. 用户进入 `/questions` 浏览问题列表。
2. 根据最新、最高悬赏或最热门进行排序。
3. 用户可发布新问题，填写标题、内容、悬赏积分和标签。
4. 其他用户进入问题详情提交回答。
5. 用户可对回答投票，并将满意回答标记为已采纳。

### 7.5 企业管理流程

1. 用户进入 `/enterprise`。
2. 未创建企业时填写企业名称、行业、规模和套餐类型。
3. 创建成功后进入企业管理面板。
4. 管理员可邀请成员、查看成员列表、查看企业课程和学习统计。
