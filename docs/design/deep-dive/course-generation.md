# 课程生成流程详细设计

## 流程概述

```
用户输入 → 文档解析 → 大纲生成 → 场景生成 → TTS合成 → 存储 → 完成
```

## 各阶段详细设计

### 1. 文档解析阶段

| 步骤 | 操作 | 输出 |
|------|------|------|
| 1.1 | 接收用户输入（文件上传或主题描述） | 原始数据 |
| 1.2 | PDF解析（MinerU增强）或Word/Markdown解析 | 结构化文本 |
| 1.3 | 文本分段和清洗 | 清洁文本片段 |
| 1.4 | 关键信息提取 | 主题、关键词、章节 |

**技术实现**:
- PDF：MinerU库（开源文档解析增强）
- Word：mammoth.js
- Markdown：marked.js
- 分段：按段落和章节自动分割
- Token消耗：10-20 Token

### 2. 大纲生成阶段

| 步骤 | 操作 | 输出 |
|------|------|------|
| 2.1 | 调用LLM分析文本 | 分析结果 |
| 2.2 | 生成课程大纲结构 | OutlineItem[] |
| 2.3 | 用户确认或调整大纲 | 最终大纲 |
| 2.4 | 返回大纲预览 | JSON大纲 |

**LLM调用**:
- 模型：GPT-4o 或 Claude 3.5 Sonnet
- Prompt：商业策略课程大纲生成提示词
- 输出格式：JSON OutlineItem[]
- Token消耗：20-30 Token

**大纲结构**:
```json
{
  "id": "uuid",
  "title": "课程标题",
  "children": [
    {
      "id": "uuid",
      "title": "第一章：市场分析概述",
      "type": "chapter",
      "children": [
        {"id": "uuid", "title": "市场规模分析", "type": "section"},
        {"id": "uuid", "title": "市场增长趋势", "type": "section"},
        {"id": "uuid", "title": "互动：市场预测模拟", "type": "interactive"}
      ]
    }
  ]
}
```

### 3. 场景生成阶段

| 步骤 | 操作 | 输出 |
|------|------|------|
| 3.1 | 遍历大纲每个节点 | 节点列表 |
| 3.2 | 根据节点类型生成场景 | Scene |
| 3.3 | 生成幻灯片内容 | SlideElement[] |
| 3.4 | 生成图片（可选） | 图片URL |
| 3.5 | 存储场景数据 | PostgreSQL |

**场景类型生成**:

| 类型 | 生成逻辑 | Token消耗 |
|------|---------|-----------|
| slide | LLM生成幻灯片元素（文本、图形、图表） | 5-10 Token |
| quiz | LLM生成问题和选项 | 3-5 Token |
| interactive | LLM生成互动脚本（决策树、模拟） | 10-15 Token |
| pbl | LLM生成项目任务描述 | 8-12 Token |

**幻灯片元素生成**:
```typescript
// LLM输出示例
{
  "elements": [
    {"type": "text", "content": "市场规模：$1.5万亿", "position": {...}},
    {"type": "chart", "content": "柱状图：市场份额", "position": {...}},
    {"type": "shape", "content": "矩形：SWOT分析框架", "position": {...}}
  ]
}
```

### 4. TTS合成阶段

| 步骤 | 操作 | 输出 |
|------|------|------|
| 4.1 | 提取幻灯片讲解文本 | 文本列表 |
| 4.2 | 调用TTS服务 | 音频URL |
| 4.3 | 关联音频到场景 | audio_url |

**TTS服务**:
- OpenAI TTS：tts-1, tts-1-hd
- MiniMax TTS：中文优化
- Google TTS：多语言支持
- Token消耗：5-10 Token

### 5. 异步任务管理

| 组件 | 说明 |
|------|------|
| 任务队列 | Redis队列存储任务状态 |
| SSE推送 | 实时推送生成进度 |
| 进度存储 | PostgreSQL任务表 |
| 暂停恢复 | 支持任务暂停和恢复 |

**SSE消息格式**:
```
Event: progress
Data: {"percent": 30, "message": "生成场景 3/10"}

Event: scene
Data: {"scene_id": "uuid", "type": "slide", "content": {...}}

Event: complete
Data: {"classroom_id": "uuid", "status": "completed"}
```

### 6. 错误处理

| 错误类型 | 处理方式 |
|----------|---------|
| LLM调用失败 | 重试3次，降级模型 |
| TTS合成失败 | 跳过音频，纯文字模式 |
| 文档解析失败 | 提示用户重新上传 |
| Token不足 | 提示充值，暂停生成 |

## 性能优化

| 优化点 | 方法 |
|--------|------|
| 大纲生成 | 缓存常见主题大纲模板 |
| 场景生成 | 并行生成多个场景 |
| 图片生成 | 使用CDN缓存 |
| TTS合成 | 异步合成，不阻塞主流程 |

## 数据流图

```
┌─────────────┐
│  用户输入   │
└─────────────┘
      ↓
┌─────────────┐
│  文档解析   │ → Token扣减（10-20）
└─────────────┘
      ↓
┌─────────────┐
│  大纲生成   │ → Token扣减（20-30）
└─────────────┘
      ↓ SSE推送
┌─────────────┐
│  场景生成   │ → Token扣减（5-15/场景）
└─────────────┘
      ↓ SSE推送
┌─────────────┐
│  TTS合成    │ → Token扣减（5-10）
└─────────────┘
      ↓
┌─────────────┐
│   存储      │ → PostgreSQL
└─────────────┘
      ↓
┌─────────────┐
│   完成      │ → SSE推送complete
└─────────────┘
```
