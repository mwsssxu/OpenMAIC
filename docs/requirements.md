## 1. 引言

### 1.1 编写目的

本需求规格说明书旨在明确 OpenMAIC 智能教学平台的功能需求、性能需求和技术需求，为项目开发、测试、验收提供依据，同时作为后续维护和升级的参考文档。

**目标读者**：
- 项目经理
- 开发工程师
- 测试工程师
- 产品经理
- 用户代表
- 运维工程师

### 1.2 项目背景

#### 1.2.1 问题陈述

当前在线教育领域存在以下痛点：

1. **内容制作成本高**：传统课件制作需要专业教师花费大量时间，录制课程、编写教案、设计测验
2. **学习体验单一**：录播课程缺乏互动，学员疑问无法及时解答，学习效率低
3. **个性化不足**：统一课程无法适应不同学员的知识水平和学习节奏
4. **企业培训难落地**：企业缺乏专业讲师，培训内容更新慢，效果难以评估

#### 1.2.2 市场机会

随着大语言模型（LLM）技术的发展，AI 已具备：
- 自动生成教学内容的能力
- 实时对话答疑的能力
- 多模态内容（公式、图表、代码）渲染能力

这为打造"AI 私教"级教学体验提供了技术基础。

#### 1.2.3 项目定位

**OpenMAIC** = **Open** + **MAIC** (Multi-modal AI Classroom)

定位为 **AI 驱动的智能教学平台**，让每个人都能获得个性化、高质量的教育体验。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| MAIC | Multi-modal AI Classroom，多模态 AI 课堂 |
| 课程 | 一套完整的学习内容，包含大纲、多个场景（幻灯片/测验） |
| 场景 | 课程中的一个学习单元，可以是幻灯片讲解或测验评估 |
| 智能体 | AI 讲师，负责讲解内容、回答问题、调用白板 |
| 白板 | 实时展示区域，用于渲染公式、图表、代码等教学内容 |
| 大纲 | 课程的结构化目录，定义学习顺序和知识点 |
| 知识库 | 企业/个人的文档资料库，支持 AI 问答 |

|------|------|----------|

| 提升学习体验 | 实时互动、个性化讲解 | 学员满意度 > 90% |
| 提高学习效率 | 自适应学习路径 | 学习完成率提升 50% |

#### 2.2.1 包含功能

- 课程自动生成（大纲、幻灯片、测验）
- AI 智能体实时讲解与答疑
- 多模态白板渲染（公式、图表、代码）

- 游戏化激励系统
- 企业知识库与问答

## 3. 功能需求

### 3.1 课程生成模块

#### 3.1.1 功能概述

AI 自动生成完整的课程内容，包括大纲、幻灯片、测验题。

#### 3.1.2 功能列表

| 功能编号 | 功能名称 | 优先级 | 描述 |
|----------|----------|--------|------|
| F-3.1-01 | 创建课程 | P0 | 用户输入主题，AI 生成课程大纲 |
| F-3.1-02 | 大纲编辑 | P1 | 用户可手动调整大纲结构 |
| F-3.1-03 | 场景生成 | P0 | 根据大纲自动生成幻灯片/测验场景 |
| F-3.1-04 | 内容预览 | P1 | 预览生成的幻灯片和测验 |
| F-3.1-05 | 课程发布 | P0 | 发布课程供学习使用 |
| F-3.1-06 | 多语言支持 | P1 | 支持中英文等语言生成 |
| F-3.1-07 | 模板复用 | P2 | 基于已有课程快速创建 |

#### 3.1.3 详细需求

**F-3.1-01 创建课程**

输入：
- 课程主题（必填）：如"Python 入门教程"
- 目标受众（可选）：如"初学者"、"中级"
- 学习目标（可选）：如"掌握基本语法"
- 语言（默认中文）

输出：
- 课程 ID
- 课程名称
- 课程大纲（结构化知识点列表）
- 预计学习时长

流程：
```
1. 用户输入主题信息
2. 系统调用 LLM 生成大纲
3. 展示大纲供用户确认/调整
4. 用户确认后生成场景内容
5. 课程创建完成
```

验证规则：
- 主题长度：2-100 字符
- 大纲层级：最多 3 级
- 场景数量：每章节 2-5 个场景

**F-3.1-03 场景生成**

场景类型：
| 类型 | 说明 | 内容格式 |
|------|------|----------|
| slide | 幻灯片讲解 | 标题、要点、公式、图表 |
| quiz | 测验评估 | 单选、多选、判断、简答题 |

幻灯片元素：
- 文本内容（Markdown 支持）
- 数学公式（LaTeX 支持）
- 图表（柱状图、饼图、折线图）
- 表格
- 代码块（语法高亮）
- 形状（矩形、圆形、箭头）

测验题型：
- 单选题：选项 2-5 个
- 多选题：选项 2-5 个
- 判断题：是/否
- 简答题：AI 批改

### 3.2 智能教学模块

#### 3.2.1 功能概述

AI 智能体实时讲解课程内容，回答学员问题，调用白板演示。

#### 3.2.2 功能列表

| 功能编号 | 功能名称 | 优先级 | 描述 |
|----------|----------|--------|------|
| F-3.2-01 | 场景讲解 | P0 | AI 智能体讲解当前场景内容 |
| F-3.2-02 | 对话答疑 | P0 | 学员提问，AI 实时回答 |
| F-3.2-03 | 白板演示 | P0 | AI 调用白板绘制公式、图表 |
| F-3.2-04 | 场景导航 | P1 | 切换场景，进度追踪 |
| F-3.2-05 | 语音播报 | P2 | 课程内容语音合成 |
| F-3.2-06 | 学习建议 | P1 | AI 分析学习情况，给出建议 |

#### 3.2.3 详细需求

**F-3.2-01 场景讲解**

输入：
- 场景 ID
- 场景类型（slide/quiz）
- 场景内容

输出：
- 讲解文本（流式输出）
- 白板动作（可选）
- 语音播报（可选）

讲解流程：
```
1. 学员进入场景
2. AI 智能体开始讲解
3. 讲解过程中调用白板绘制
4. 学员可随时打断提问
5. AI 回答问题后继续讲解
```

白板动作类型：
| 动作 | 参数 | 说明 |
|------|------|------|
| wb_draw_text | content, fontSize, color | 绘制文本 |
| wb_draw_shape | shape, fillColor | 绘制形状 |
| wb_draw_chart | chartType, data | 绘制图表 |
| wb_draw_table | data | 绘制表格 |
| wb_draw_code | code, language | 绘制代码 |
| wb_draw_latex | latex | 绘制公式 |
| wb_clear | - | 清空白板 |

**F-3.2-02 对话答疑**

对话特性：
- **上下文记忆**：记住当前场景和之前对话
- **场景感知**：知道正在讲什么内容
- **知识检索**：从课程内容中查找答案
- **流式输出**：实时显示回答，减少等待

对话示例：
```
学员：这个公式是什么意思？
AI：这是一个二次方程的求根公式...
    [白板绘制公式]
    公式中 a、b、c 分别代表...
```

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 要求 | 说明 |
|------|------|------|
| API 响应时间 | < 500ms | 常规 API 请求 |
| 流式首字延迟 | < 2s | AI 流式输出首字 |
| 白板渲染帧率 | > 30fps | 白板动画流畅度 |
| 页面加载时间 | < 3s | 首屏加载 |
| 并发用户数 | > 1000 | 单节点并发能力 |

### 4.2 可用性需求

| 指标 | 要求 |
|------|------|
| 系统可用性 | > 99.9% |
| 故障恢复时间 | < 30min |
| 数据备份频率 | 每日备份 |

### 4.3 安全需求

#### 4.3.1 认证与授权

| 需求 | 说明 |
|------|------|
| 用户认证 | JWT Token + OAuth2 |
| 密码安全 | bcrypt 加密，强度因子 ≥ 12 |
| 会话管理 | Token 过期时间 7 天 |
| 权限控制 | RBAC 角色权限模型 |

#### 4.3.2 数据安全

| 需求 | 说明 |
|------|------|
| 传输加密 | HTTPS TLS 1.2+ |
| 存储加密 | 敏感数据加密存储 |
| SQL 注入防护 | ORM 参数化查询 |
| XSS 防护 | 输入过滤、输出编码 |

#### 4.3.3 API 安全

| 需求 | 说明 |
|------|------|
| 速率限制 | 单用户 100 req/min |
| CORS 配置 | 白名单域名 |
| API Key 管理 | 加密存储、定期更换 |

### 4.4 可扩展性需求
