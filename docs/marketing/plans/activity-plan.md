## 七、社区UGC活动

### 7.1 活动设计

| 项目 | 内容 |
|------|------|
| 活动名称 | 【优质笔记征集】 |
| 活动时间 | 每月15日-月底 |
| 目标用户 | 学习者、创作者 |
| 活动内容 | 发布学习笔记，评选优质笔记 |
| 活动奖励 | Top3：100Token + 证书；被采纳笔记：50积分 |

### 7.2 评选标准

| 标准 | 权重 | 说明 |
|------|------|------|
| 内容质量 | 40% | 信息准确、结构清晰 |
| 学习价值 | 30% | 对其他学习者有帮助 |
| 创意表达 | 20% | 表达方式有创意 |
| 视觉呈现 | 10% | 排版美观、配图恰当 |

### 7.3 活动流程

```
活动公告发布
    ↓
用户发布笔记（活动期间）
    ↓
活动结束后评选（AI评分+人工审核）
    ↓
公布获奖名单
    ↓
发放奖励
    ↓
优质笔记收录到课程补充素材
```
