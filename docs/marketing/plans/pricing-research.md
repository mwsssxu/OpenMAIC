## 二、侧伴成本核算（基于实际架构）

### 2.1 单次课程生成成本

| 成本项目 | 费用 | 说明 |
|---------|------|------|
| LLM API调用（qwen3.6-plus） | ¥0.5-2/次 | 根据模型和token数 |
| TTS语音合成 | ¥0.1-0.3/次 | 语音讲解 |
| 存储 | ¥0.05/次 | 课程内容存储 |
| **合计** | **¥0.65-2.35/次** | 单次生成成本 |

### 2.2 月度运营成本（预估）

| 成本项目 | 月费用 | 说明 |
|---------|--------|------|
| 云服务器 | ¥500-1000 | 云服务费用 |
| 数据库 | ¥200-500 | PostgreSQL/MongoDB |
| API调用（预估用户量） | ¥2000-5000 | LLM/TTS |
| CDN/存储 | ¥200-500 | 文件存储 |
| **合计** | **¥2900-7000/月** | 基础运营成本 |

### 2.3 盈亏平衡计算

假设单次成本 ¥1.5：
- 月订阅 ¥29 → 用户需生成 ≥20次才能覆盖成本
- Token制 ¥9.9=50Token → 成本 ¥75，需定价 ≥¥15 才能盈利
- Token制 ¥29=150Token → 成本 ¥225，需定价 ≥¥25 才能盈利

**结论**：Token制定价必须确保每Token价值 > ¥0.15 才能盈利。
当前方案（¥9.9=50Token → ¥0.20/个）有合理利润空间。
