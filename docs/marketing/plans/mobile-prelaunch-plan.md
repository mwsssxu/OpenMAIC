## 三、定价方案验证

### 3.1 定价方案选项

| 方案 | 价格 | 特点 | 适合用户 |
|-----|------|------|---------|
| **方案A：按次付费** | ¥3-5/次课程生成 | 灵活、低门槛 | 轻度用户 |
| **方案B：月度订阅** | ¥29/月无限生成 | 高频用户友好 | 重度用户 |
| **方案C：Token制** | ¥9.9=100Token，¥49=600Token | 通用、可累积 | 所有用户 |
| **方案D：免费+增值** | 免费3次/月，付费解锁高级功能 | 获客成本低 | 新用户转化 |

### 3.2 定价调研方法

**方法1：小红书投票帖**
- 发布内容："AI学习App定价调研，你选哪个？"
- 评论区收集反馈

**方法2：用户问卷**
- 创建飞书表单，收集定价偏好
- 通过社群、朋友圈分发

**方法3：竞品对比**
- 调研同类产品定价
- 找差异化定价空间

### 3.3 竞品定价参考

| 产品 | 定价模式 | 价格 | 说明 |
|-----|---------|------|------|
| ChatGPT Plus | 月订阅 | $20/月 | 高端定位 |
| Kimi | 免费+增值 | 免费 | 大厂免费策略 |
| 豆包 | 免费 | 免费 | 字跳动 |
| 文心一言 | 月订阅 | ¥59.9/月 | 百度 |
| 通义千问 | 免费+增值 | 免费+会员 | 阿里 |

**建议**：
- 初期采用**方案D（免费+增值）**获客
- 后期验证后切换到**方案C（Token制）**

## 五、种子用户运营

### 5.1 内测用户权益

| 权益 | 说明 |
|-----|------|
| 优先体验 | 产品首发第一时间通知 |
| 永久免费额度 | 内测用户永久享受每月100 Token |
| 功能建议权 | 提的功能建议优先开发 |
| 专属社群 | 加入内测用户专属群 |
| 周边礼品 | 完成反馈送侧伴周边 |

### 5.2 内测用户筛选

**硬性条件**：
- 有真实学习需求
- 愿意每周反馈1次使用体验

**优先条件**：
- 小红书/知乎有影响力
- 教育/科技行业从业者
- 学习博主

### 5.3 反馈收集

**每周收集**：
- 使用频率
- 最喜欢的功能
- 最不满意的地方
- 建议新增的功能
- 愿意付费的价格区间

- 小红书投票帖

- 收集 100+ 反馈

### 第3步：成本核算（第2周）
- 计算 API 调用成本

- 确定 2-3 个备选方案
- 计算盈亏平衡点
- 制定价格测试计划

### 第5步：A/B 测试（产品上架后）

- 收集转化数据
- 优化定价策略
