## 三、内容生产流程

### 3.1 内容生产流程图

```
选题确定 → 资料收集 → 内容撰写 → 审核 → 发布 → 效果追踪 → 优化
```

### 3.2 各角色职责

| 角色 | 职责 | 产出 |
|------|------|------|
| 内容策划 | 选题确定、资料收集 | 选题清单、资料包 |
| 内容撰写 | 文案撰写、视频脚本 | 初稿、脚本 |
| 内容审核 | 质量、合规审核 | 审核意见 |
| 内容发布 | 发布、互动回复 | 发布记录 |
| 数据分析 | 效果追踪、优化建议 | 数据报告 |

### 3.3 内容质量标准

| 内容类型 | 字数/时长 | 质量要点 |
|---------|---------|---------|
| 小红书笔记 | 300-500字 | 图片精美、话题热门、开头吸引 |
| 知乎回答 | 500-2000字 | 结构清晰、信息详实、引用数据 |
| B站视频 | 3-10分钟 | 清晰讲解、字幕完整、封面吸引 |
| 抖音视频 | 15-60秒 | 开头3秒吸引、结尾有钩子 |
| 微博 | 140字内 | 信息简洁、配图/视频 |
| 公众号文章 | 1500-3000字 | 深度内容、排版精美、可分享 |
