# 主项目需求 (packages/main-project)

## 概述

Next.js 16 Web 应用，提供完整的课程生成、播放、协作学习体验。是平台的核心前端。

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Next.js | 16.x | App Router, SSR/SSG |
| React | 19.x | UI 组件 |
| TypeScript | 5.x | 类型安全 |
| Tailwind CSS | 4.x | 样式系统 |
| shadcn/ui | latest | 组件库 |
| Zustand | 5.x | 状态管理 |
| LangGraph | - | 多智能体编排 |
| Vercel AI SDK | - | LLM 统一调用 |

## 功能需求

### 1. 用户认证模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 邮箱注册/登录 | P0 | JWT Token 认证 |
| OAuth 登录 | P0 | Apple/Google/微信 |
| Token刷新 | P0 | Refresh Token机制 |
| 用户资料管理 | P1 | 昵称、头像、简介 |
| 账户设置 | P1 | 密码修改、通知偏好 |

**详细需求**:
- 注册：邮箱验证码、密码强度检测
- OAuth：Apple Sign In、Google OAuth 2.0、微信扫码登录
- Token：access_token 24h 有效期，refresh_token 7d 有效期
- 退出登录时清除本地状态和 Token

### 2. 课程生成模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 文档上传 | P0 | PDF/Word/Markdown |
| 主题输入 | P0 | 文本描述生成 |
| 大纲预览 | P0 | 生成前结构调整 |
| 场景生成 | P0 | 幻灯片、问答、互动、PBL |
| TTS语音合成 | P1 | 多语音角色 |
| 进度追踪 | P1 | 异步任务状态 |

**详细需求**:
- 文档解析：支持 PDF（含 MinerU 增强解析）、Word、Markdown
- 大纲结构：章节、知识点、互动点、测试点
- 场景类型：
  - slide: 幻灯片讲解（含图表、公式）
  - quiz: 选择题/判断题/简答题
  - interactive: 模拟决策、案例分析
  - pbl: 项目式学习任务
- TTS：支持 OpenAI/MiniMax/Google TTS，多角色语音
- 异步生成：SSE 实时推送进度，支持暂停/恢复

### 3. 课程播放模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 场景播放 | P0 | 幻灯片、语音、动画 |
| 进度控制 | P0 | 播放/暂停/快进/快退 |
| 白板交互 | P0 | 实时绘制/文本/图表 |
| 笔记记录 | P0 | 个人笔记、时间戳关联 |
| 指针跟随 | P1 | AI 教师焦点指示 |
| 进度追踪 | P1 | 学习进度保存 |

**详细需求**:
- 播放引擎：状态机驱动（idle → playing → live）
- 白板支持：
  - 画笔工具（多种颜色/粗细）
  - 文本工具
  - 图形工具（矩形、圆形、箭头）
  - 图表工具（柱状图、折线图）
  - 橡皮擦
- 笔记：Markdown 支持，时间戳自动关联场景
- 指针：激光笔、聚光灯效果
- 进度：本地 IndexedDB 存储，云端同步

### 4. 多智能体讨论模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 实时讨论 | P0 | SSE 流式响应 |
| 角色切换 | P0 | 首席分析师、市场专家等 |
| 话题引导 | P0 | AI 主动提问 |
| 用户参与 | P1 | 用户发言、点赞 |
| 讨论记录 | P1 | 历史回放 |

**详细需求**:
- 智能体角色：
  - Chief Analyst（首席分析师）：整体分析框架
  - Market Expert（市场专家）：市场趋势分析
  - Competition Expert（竞争专家）：竞争格局分析
  - Finance/Risk Expert（财务/风险专家）：财务风险评估
- 讨论流程：LangGraph 状态机编排
- 用户参与：通过聊天输入框发言
- 记录格式：JSON 时间线格式，可回放

### 5. 协作模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 课堂邀请 | P0 | 邀请链接/二维码 |
| 共享白板 | P0 | WebSocket 实时同步 |
| 协作笔记 | P1 | 选择性共享 |
| 实时讨论 | P1 | 文字聊天 |
| 参与者列表 | P1 | 在线状态显示 |

**详细需求**:
- 邀请机制：生成唯一课堂 ID，支持邀请链接和二维码
- 白板同步：CRDT 算法解决并发冲突
- 笔记共享：用户可选择公开笔记或私有笔记
- 聊天：课堂内实时文字聊天
- 状态：显示参与者头像、在线状态

### 6. Token/积分模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| Token账户 | P0 | 购买/消耗/余额 |
| 积分账户 | P0 | 赚取/消耗/兑换 |
| 积分兑换 | P0 | 100积分→10 Token |
| 消费记录 | P0 | 交易流水查询 |
| 试用赠送 | P1 | 新用户礼包 |

**详细需求**:
- Token 获取：
  - 购买套餐（￥10/100 Token, ￥50/600 Token, ￥100/1500 Token）
  - 积分兑换
  - 邀请奖励
  - 新用户试用（200 Token）
- Token 消耗：
  - 课程生成（10-50 Token）
  - AI交互（1 Token/轮）
  - 下载报告（5 Token）
- 积分获取：
  - 完成课程（10-50积分）
  - 每日签到（5积分）
  - 问答被采纳（10积分）
  - 笔记被购买（70%收益）
  - 邀请好友（20积分）
- 积分消耗：
  - 问答悬赏（设置积分奖励）
  - 兑换 Token

### 7. 问答悬赏模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 问题发布 | P0 | 标题、内容、悬赏积分 |
| 问题列表 | P0 | 分类、筛选、排序 |
| 回答提交 | P0 | 文字、图片、附件 |
| 采纳答案 | P0 | 提问者采纳，积分转移 |
| 举报管理 | P1 | 违规内容举报 |

**详细需求**:
- 问题分类：市场分析、财务分析、竞争策略、风险管理等
- 悬赏范围：10-500 积分
- 答案评分：用户评分、采纳标记
- 积分流转：采纳后积分 90% 给回答者，10% 平台
- 反作弊：抄袭检测、刷分检测

### 8. 支付模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| Token购买 | P0 | 微信支付/支付宝 |
| 套餐展示 | P0 | 价格对比、优惠信息 |
| 订单管理 | P0 | 创建、查询、取消 |
| 支付回调 | P0 | 验证、入账 |
| 发票申请 | P2 | 企业用户发票 |

**详细需求**:
- 支付方式：微信支付、支付宝
- 套餐：
  - 基础包：￥10 = 100 Token
  - 标准包：￥50 = 600 Token（赠 20%）
  - 高级包：￥100 = 1500 Token（赠 50%）
- 新用户优惠：首购 50% 折扣
- 订单状态：created → paid → cancelled

### 9. 邀请模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 邀请码生成 | P0 | 个人专属码 |
| 邀请分享 | P0 | 链接、海报 |
| 邀请记录 | P0 | 已邀请人数 |
| 奖励发放 | P0 | 自动发放 |

**详细需求**:
- 奖励规则：
  - 一级邀请：邀请人 20 积分 + 50 Token，被邀请人 100 Token
  - 二级邀请：邀请人 10 积分
  - 三级邀请：邀请人 5 积分
- 邀请码：nanoid 生成，用户唯一
- 统计：邀请人数、注册人数、活跃人数

### 10. 游戏化模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 连续打卡 | P0 | 每日学习签到 |
| 每日任务 | P0 | 任务列表、完成奖励 |
| 联赛排名 | P0 | 周联赛、升降级 |
| 徽章成就 | P1 | 成就解锁、展示 |
| 学习统计 | P1 | 可视化数据 |

**详细需求**:
- 打卡：
  - 学习 15min 即打卡成功
  - 连续打卡奖励递增（第2天+5，第7天+30）
  - 断签保护（积分购买）
- 每日任务：
  - 完成 1 课程（10积分）
  - 参与讨论 1 次（5积分）
  - 回答问题 1 次（5积分）
  - 学习 30min（10积分）
- 联赛：
  - 铜牌、银牌、金牌、钻石、大师、冠军
  - 每周积分排名升降级
- 徽章：
  - 学习类：完成 10 课程、连续 30 天打卡
  - 社交类：邀请 10 人、回答被采纳 20 次
  - 特殊类：首购、年度活跃

### 11. 学习搭子模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 搭子生成 | P0 | 6 种性格类型 |
| 情绪互动 | P0 | 鼓励/竞争/吐槽 |
| 学习统计 | P0 | 与搭子对比 |
| 进度同步 | P1 | 搭子学习进度 |

**详细需求**:
- 搭子类型：
  - 激励型（鼓励者）："你今天做得太棒了！"
  - 竞争型（挑战者）："我已完成 3 课程，你呢？"
  - 陪伴型（倾听者）："休息一下吧，我等你"
  - 吐槽型（毒舌者）："怎么还没开始学习？"
  - 知识型（学者）："这个知识点很有深度..."
  - 默契型（伙伴）："我们一起完成这个目标"
- 情绪触发：打卡、完成任务、断签、长时间未学习
- AI 生成：LiteLLM 调用不同模型生成搭子对话

### 12. 学习匹配模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 课程匹配 | P0 | 相同课程学习者 |
| 知识匹配 | P0 | 相似知识点 |
| 匹配推荐 | P0 | 推荐学习伙伴 |
| 笔记共享 | P1 | 匹配用户笔记可见 |

**详细需求**:
- 匹配算法：基于课程 ID、知识点标签、学习进度
- 推荐逻辑：优先匹配进度相近、知识点重叠度高的用户
- 笔记权限：
  - 公开笔记：所有人可见
  - 付费笔记：购买后可见（设置价格 10-100 积分）
  - 匹配笔记：仅匹配用户可见（免费）
- 防作弊：付费笔记版权保护，抄袭举报

### 13. 共享笔记模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 笔记发布 | P0 | Markdown 格式 |
| 笔记定价 | P0 | 10-100 积分 |
| 笔记购买 | P0 | 积分支付 |
| 笔记展示 | P1 | 笔记市场 |
| 收益统计 | P1 | 作者收益 |

**详细需求**:
- 发布流程：
  - 选择笔记内容
  - 设置可见范围（公开/付费/匹配）
  - 设置价格（付费模式）
  - 确认发布
- 收益分配：作者 70%，平台 30%
- 购买流程：积分支付 → 笔记解锁 → 永久可见
- 质量：笔记评分系统，低评分笔记降权
