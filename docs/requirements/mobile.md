# 移动端需求 (packages/mobile)

## 概述

Expo React Native 移动应用，提供轻量化的课程播放、学习打卡、问答互动体验，适配手机和平板。

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Expo | 52.x | React Native 框架 |
| expo-router | 4.x | 文件路由系统 |
| React Native | 0.76.x | 移动端 UI |
| TypeScript | 5.x | 类型安全 |
| Skia | 1.8.x | 高性能渲染 |
| Zustand | 5.x | 状态管理 |
| MMKV | 3.x | 本地存储 |
| expo-secure-store | 14.x | 安全存储 |

## 功能需求

### 1. 用户认证模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 邮箱登录 | P0 | JWT Token 认证 |
| OAuth 登录 | P0 | Apple/Google |
| Token 存储 | P0 | SecureStore 安全存储 |
| 自动登录 | P0 | Token 自动刷新 |
| 用户资料 | P1 | 头像、昵称 |

**详细需求**:
- SecureStore 存储 access_token、refresh_token
- 自动刷新：Token 过期前 1h 自动刷新
- OAuth：Apple Sign In（iOS）、Google Sign In
- 登录页面：邮箱密码表单、OAuth 按钮

### 2. 课程播放模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 场景播放 | P0 | 幻灯片、语音 |
| 进度控制 | P0 | 播放/暂停 |
| 手势导航 | P0 | 左右滑动切换场景 |
| 白板绘制 | P1 | Skia 高性能渲染 |
| 笔记记录 | P1 | 简化笔记输入 |

**详细需求**:
- 播放控制：
  - 自动播放/手动播放模式
  - 场景切换手势（左滑下一场景，右滑上一场景）
  - 双击暂停/播放
- Skia 渲染：
  - 幻灯片渲染（文本、图形、图表）
  - 白板绘制（画笔、文本）
  - 高性能 60fps 渲染
- 笔记：简化输入，支持文本和时间戳
- 语音：expo-av 播放 TTS 音频

### 3. 学习打卡模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 打卡入口 | P0 | 学习完成打卡 |
| 打卡记录 | P0 | 本地记录 |
| 连续天数 | P0 | 显示连续打卡 |
| 打卡动画 | P1 | 成功动画效果 |

**详细需求**:
- 打卡触发：课程学习完成或学习时长达标
- 本地存储：MMKV 存储打卡数据
- 动画：打卡成功展示动画和积分奖励

### 4. 问答互动模块

| 功能 | 优先级 | 说明 |

**详细需求**:

- 悬赏显示：积分数量、回答者数量

### 5. 问答悬赏模块

| 功能 | 优先级 | 说明 |
|------|--------|------|

### 10. 课程发现模块

## UI/UX 设计规范

### 设计风格

| 元素 | 规范 |
|------|------|
| 主色调 | 商业蓝 #1e3a5f |
| 辅色调 | 成功绿 #48bb78、金 #d4a017 |
| 字体 | 系统字体（中文） |
| 圆角 | 12px 卡片 |
| 间距 | 16px 标准 |

### 响应式适配

| 设备 | 适配说明 |
|------|---------|
| 手机 | 375px 宽度、单列布局 |
| 平板 | 768px 宽度、双列布局 |
| 大屏 | 1024px+ 宽度、三列布局 |

### 手势交互

| 手势 | 动作 |
|------|------|
| 左滑 | 下一场景/下一项 |
| 右滑 | 上一场景/上一项 |
| 上滑 | 刷新列表 |
| 下拉 | 退出详情页 |
| 双击 | 播放/暂停 |
| 长按 | 显示选项菜单 |

## 性能需求

| 指标 | 目标 |
|------|------|
| 冷启动 | < 3s |
| 场景切换 | < 300ms |
| 白板渲染 | 60fps |
| 内存占用 | < 100MB |
| 网络请求 | < 5s |

## 安全需求

| 需求 | 说明 |
|------|------|
| Token 安全存储 | SecureStore |
| HTTPS 通信 | 所有 API |
| 本地数据加密 | MMKV 加密 |
| 权限控制 | 最小权限原则 |

## 离线支持

| 功能 | 离线支持 |
|------|---------|
| 已下载课程 | 完全离线 |
| 个人笔记 | 完全离线 |
| 打卡记录 | 本地存储，联网同步 |
| 问答列表 | 需联网 |

**详细需求**:
- 课程下载：支持下载已购课程离线观看
- 笔记同步：本地 SQLite + 云端同步
- 打卡同步：本地 MMKV + 联网同步积分
