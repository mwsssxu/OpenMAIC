# 协作系统需求

## 概述

多用户实时协作系统，支持共享白板、协作笔记、实时聊天等功能，确保数据隔离和安全。

## 技术栈

| 技术 | 用途 |
|------|------|
| WebSocket | 实时双向通信 |
| Redis | 连接状态管理、消息队列 |
| CRDT (Yjs) | 冲突解决算法 |
| PostgreSQL | 协作数据持久化 |

## 功能需求

### 1. 课堂邀请模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 邀请链接生成 | P0 | unique classroom ID |
| 二维码生成 | P0 | 移动端扫码加入 |
| 邀请有效期 | P1 | 可设置过期时间 |
| 邀请人数限制 | P1 | 最大参与者数量 |

**详细需求**:
- 链接格式：`https://openmaic.com/classroom/{id}/invite`
- 二维码：QRCode 库生成，嵌入邀请链接
- 有效期：默认 7 天，可设置 1-30 天
- 人数限制：默认 50 人，可设置 10-200 人

### 2. 共享白板模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 实时绘制同步 | P0 | WebSocket 推送 |
| 冲突解决 | P0 | CRDT 算法 |
| 绘制工具 | P0 | 画笔、文本、图形 |
| 历史回放 | P1 | 白板操作历史 |
| 导出功能 | P1 | PNG/PDF 导出 |

**详细需求**:
- 绘制工具：
  - 画笔（颜色、粗细）
  - 文本（字体、大小）
  - 图形（矩形、圆形、箭头）
  - 图表（柱状图、折线图）
  - 橡皮擦
- CRDT：
  - 使用 Yjs 库实现 CRDT
  - 解决并发编辑冲突
  - 支持撤销/重做
- 同步：
  - WebSocket 实时推送绘制操作
  - Redis 存储白板状态
  - 历史记录持久化

### 3. 协作笔记模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 选择性共享 | P0 | 用户选择共享范围 |
| 实时同步 | P0 | WebSocket 推送 |
| 权限管理 | P0 | 共享权限设置 |
| 笔记聚合 | P1 | 课堂笔记汇总 |

**详细需求**:
- 共享范围：
  - 私有：仅自己可见
  - 匹配用户：仅匹配用户可见（免费）
  - 付费：所有人购买后可见（设置价格）
  - 公开：所有人可见（免费）
- 权限：
  - 可见权限
  - 可编辑权限（协作模式下）
- 同步：
  - WebSocket 实时同步共享笔记
  - CRDT 解决并发编辑冲突

### 4. 实时聊天模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 文字聊天 | P0 | WebSocket 实时消息 |
| 消息历史 | P0 | PostgreSQL 存储 |

### 5. 参与者管理模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 参与者列表 | P0 | 在线用户列表 |
| 在线状态 | P0 | 实时更新状态 |
| 邀请发送 | P1 | 课堂内邀请好友 |
| 离开通知 | P1 | 用户离开提醒 |

**详细需求**:

  - online：当前在线

### 6. 数据隔离模块

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 用户数据隔离 | P0 | 私有数据不可见 |
| 协作数据共享 | P0 | 课堂内共享数据 |
| 权限验证 | P0 | API 权限验证 |
| 数据加密 | P1 | 敏感数据加密 |

**详细需求**:
- 私有数据：
  - 个人笔记（私有模式）
  - 学习记录
  - 积分账户
  - Token 账户
- 共享数据：
  - 课堂白板（课堂内共享）
  - 共享笔记（选择共享模式）
  - 聊天记录（课堂内共享）
- 权限验证：
  - API 层：验证用户是否属于课堂
  - 数据层：查询时过滤私有数据
- 数据加密：
  - HTTPS 传输加密
  - 敏感数据（积分、Token）加密存储

### 7. 设备适配模块

| 功能 | 优先级 | 说明 |

  - 触控点大小适配

## WebSocket 消息设计

### 消息类型

| 类型 | 方向 | 说明 |
|------|------|------|
| join | client → server | 用户加入课堂 |
| leave | client → server | 用户离开课堂 |
| whiteboard_update | client ↔ server | 白板绘制更新 |
| cursor_move | client → server | 光标位置更新 |
| chat_message | client ↔ server | 聊天消息 |
| user_join | server → client | 用户加入通知 |
| user_leave | server → client | 用户离开通知 |
| note_update | client ↔ server | 笔记更新 |
| error | server → client | 错误消息 |

### 消息格式

```json
{
  "type": "whiteboard_update",
  "classroom_id": "uuid",
  "user_id": "uuid",
  "data": {
    "operation": "draw",
    "tool": "pen",
    "points": [{"x": 100, "y": 200}, {"x": 120, "y": 220}],
    "color": "#1e3a5f",
    "width": 2
  },
  "timestamp": 1634567890123
}
```

## CRDT 实现

### Yjs 集成

| 功能 | 说明 |
|------|------|
| Y.Doc | CRDT 文档 |
| Y.XmlFragment | 结构化数据 |
| Y.Map | 键值数据 |
| Y.Array | 数组数据 |

**详细需求**:
- 白板数据：
  - Y.Array 存储绘制操作
  - 每个操作包含 ID、类型、数据
- 笔记数据：
  - Y.XmlFragment 存储 Markdown
  - 支持文本、格式、图片
- 同步：
  - WebSocket 传输 Yjs 更新
  - 客户端合并更新
  - 解决冲突

## 性能需求

| 指标 | 目标 |
|------|------|
| 白板同步延迟 | < 100ms |
| 聊天消息延迟 | < 50ms |
| 支持 concurrent 用户 | 10,000+ |
| Redis 缓存命中率 | > 90% |

## 安全需求

| 需求 | 说明 |
|------|------|
| WebSocket 认证 | Token 验证 |
| 数据隔离 | API 层过滤 |
| 课堂权限验证 | 用户是否属于课堂 |
| Rate Limiting | 消息频率限制 |
