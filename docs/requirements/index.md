# 需求概述

## 平台定位

OpenMAIC Business 是一个商业策略研究学习平台，通过 AI 技术将商业文档、市场分析报告转化为交互式学习课程，支持多用户协作、实时互动、游戏化激励等现代学习体验。

## 目标用户

| 用户群体 | 核心需求 |
|---------|---------|
| 商业分析师 | 学习前沿分析方法、分享研究成果 |
| 企业管理者 | 快速掌握战略决策框架、团队协作学习 |
| 商学院学生 | 实践案例分析、互动讨论学习 |
| 自学者 | 低成本获取高质量商业知识、游戏化激励保持动力 |

## 核心价值主张

1. **AI 驱动的课程生成** - 自动将文档转化为结构化学习内容
2. **多智能体协作讨论** - 不同角色专家（首席分析师、市场专家、竞争专家、财务专家）实时互动
3. **多用户实时协作** - 共享白板、同步笔记、即时讨论
4. **游戏化激励系统** - 连续打卡、联赛排名、徽章成就、虚拟学习搭子
5. **知识共享生态** - 付费笔记、问答悬赏、学习匹配

## 子系统划分

```
OpenMAIC Business
├── packages/main-project      # Next.js Web 应用
├── packages/mobile            # Expo React Native 移动应用
├── packages/server-python     # FastAPI Python 后端
└── packages/collaboration     # 协作系统模块（WebSocket）
```

## 功能模块分类

### 基础功能
- 用户认证（OAuth + 邮箱密码）
- 课程生成与播放
- 多智能体讨论
- 笔记系统

### 增值功能
- Token/积分经济系统
- 问答悬赏系统
- 支付与订阅
- 邀请奖励机制

### 增强功能
- 虚拟学习搭子
- 学习匹配系统
- 共享笔记市场
- 游戏化系统（打卡、联赛、徽章、每日任务）

### 管理功能
- 用户管理后台
- 内容审核
- 数据统计
- 系统配置

## 数据隔离原则

- 用户私有数据：个人笔记、学习记录、积分账户
- 公开共享数据：课程内容、问答区、共享笔记
- 协作数据：课堂白板（课堂内共享）、讨论区

## 性能指标

| 指标 | 目标值 |
|------|--------|
| 课程生成响应 | < 30s（首场景） |
| 播放加载时间 | < 2s（首屏） |
| 白板同步延迟 | < 100ms |
| 支持 concurrent 用户 | 10,000+ |
| 移动端冷启动 | < 3s |

## 安全要求

- OAuth 2.0 认证流程
- JWT Token + Refresh Token 机制
- 数据传输 HTTPS 加密
- 用户数据逻辑隔离（数据库层面）
- 付费交易安全验证
- 防作弊机制（积分刷取、问答抄袭检测）
