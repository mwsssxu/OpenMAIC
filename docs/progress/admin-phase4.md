## 验收标准

| 功能 | 验收条件 |
|------|---------|
| 管理员登录 | 邮箱密码登录 → 权限验证 → 跳转正常 |
| 用户列表 | 筛选/排序/搜索 → 列表显示正常 |
| 用户操作 | 禁用/调整积分 → 操作生效正常 |
| 内容审核 | 审核列表 → 通过/拒绝 → 内容状态更新正常 |
| 数据统计 | 统计图表 → 数据正确 → 可视化正常 |
| 系统配置 | 配置修改 → 保存成功 → 系统生效正常 |

## 风险与应对

| 风险 | 应对措施 |
|------|---------|
| 管理员权限滥用 | 权限分级、操作日志 |
| 数据统计不准确 | 数据源校验、定时任务 |
| 系统配置错误 | 配置验证、回滚机制 |

## 后台管理 UI 结构

```
/admin
├── /login          # 管理员登录
├── /dashboard      # 仪表盘总览
├── /users          # 用户管理
│   ├── /list       # 用户列表
│   └── /{id}       # 用户详情
├── /content        # 内容管理
│   ├── /questions  # 问题审核
│   ├── /answers    # 回答审核
│   └── /notes      # 笔记审核
├── /statistics     # 数据统计
│   ├── /users      # 用户统计
│   ├── /classrooms # 课程统计
│   └── /economy    # 经济统计
├── /settings       # 系统配置
│   ├── /llm        # LLM 配置
│   ├── /pricing    # 价格配置
│   └── /rules      # 规则配置
└──── /logs         # 操作日志
```
