## 验收标准

| 功能 | 验收条件 |
|------|---------|
| 学习搭子 | 选择搭子类型 → 情绪触发 → 消息推送正常 |
| 学习匹配 | 完成课程 → 匹配推荐 → 推荐列表正确 |
| 共享笔记 | 发布笔记 → 设置范围 → 笔记显示正常 |
| 笔记购买 | 选择笔记 → 积分支付 → 笔记解锁正常 |
| 连续打卡 | 学习达标 → 打卡成功 → 奖励递增正确 |
| 每日任务 | 任务列表 → 完成任务 → 积分奖励正确 |
| 联赛排名 | 积分累计 → 联赛等级 → 升降级正常 |
| 徽章成就 | 触发条件 → 自动解锁 → 徽章显示正常 |

## 风险与应对

| 风险 | 应对措施 |
|------|---------|
| 搭子消息生成慢 | LiteLLM 缓存、预设模板 |
| 匹配算法不准确 | 多维度相似度、用户反馈优化 |
| 笔记抄袭 | 版权保护、举报机制 |
| 游戏化作弊 | 频率限制、反作弊检测 |
