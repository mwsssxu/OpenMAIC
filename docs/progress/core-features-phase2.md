## 验收标准

| 功能 | 验收条件 |
|------|---------|
| Token 消费 | 课程生成 → Token扣减 → 余额更新正确 |
| 积分赚取 | 完成课程 → 积分增加 → 余额更新正确 |
| 积分兑换 | 选择积分 → 兑换Token → 余额更新正确 |
| 新用户礼包 | 注册 → 自动发放礼包 → 余额显示正确 |
| 问答发布 | 发布问题 → 悬赏积分扣减 → 问题显示正确 |
| 问答回答 | 提交回答 → 回答显示 → 评分正常 |
| 问答采纳 | 采纳答案 → 积分流转 → 余额更新正确 |
| Token 购买 | 选择套餐 → 支付成功 → Token入账正确 |
| 邀请奖励 | 邀请好友注册 → 奖励发放 → 统计更新正确 |
