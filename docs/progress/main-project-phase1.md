## 风险与应对

| 风险 | 应对措施 |
|------|---------|
| LLM API 响应慢 | 使用缓存、流式响应 |
| WebSocket 并发问题 | Redis 连接池、Rate Limiting |
| 移动端性能问题 | Skia 高性能渲染、代码优化 |
| CRDT 冲突问题 | Yjs 库成熟方案、充分测试 |
