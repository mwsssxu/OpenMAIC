### Step 1: 注册账号

1. 下载小红书App
2. 注册账号（手机号）
3. 完成基础信息填写

### Step 2: 设置账号信息

| 设置项 | 内容 |
|-------|------|
| 昵称 | 侧伴开发者日记 |
| 简介 | 一个开发者做的AI学习伙伴... |
| 头像 | 开发者照片或产品Logo |
| 性别 | 根据实际情况 |
| 所在地 | 根据实际情况 |

### Step 3: 发布第一条内容

使用 `story-01-origin.md` 小红书版本
发布时间：晚8点

### Step 4: 设置话题标签

常用话题标签库：
```

#独立开发者 #创业故事 #一人公司
```

## 三、内容风格指南

### 文案调性

| 维度 | 要求 |
|-----|-----|
| **真实** | 分享真实经历，不编造 |
| **共情** | 从用户痛点出发，建立共鸣 |
| **简洁** | 500字以内，配图清晰 |
| **有温度** | 语言自然，不营销腔 |

### 图片要求

| 类型 | 建议 |
|-----|-----|
| 产品截图 | 功能界面展示 |
| 文字卡片 | 标题+要点，简洁设计 |
| 开发者照片 | 建立真实感（可选） |

### 互动要求

| 行为 | 要求 |
|-----|-----|
| **回复评论** | 发布后24小时内回复 |
| **回复私信** | 24小时内回复 |
| **语气** | 亲切、真诚、不官方腔 |

---

## 四、注意事项

1. **不要营销腔**：避免"赶快下载""限时优惠"等硬广语言
2. **保持真实**：坦诚是独立开发者，不伪装大公司
3. **积极互动**：认真回复每一条评论和私信
4. **内容连贯**：创业故事系列要有逻辑，不是碎片内容
